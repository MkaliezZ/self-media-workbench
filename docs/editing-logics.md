# 已归并的剪辑逻辑与执行边界

方法库按问题和作用机制归并；以下补回前版遗漏的内容形式，不以标题或换色重复建方法。

| 逻辑 | 判断顺序 | 当前执行 | 仍未实现 |
|---|---|---|---|
| 不露脸资料解说 | 命题→资料主画面→解释→限定结论 | 资料布局、区域提示、原生旁白/音乐轨 | 复杂资料动效 |
| 科普资料串联 | 现象→资料支持→机制→不确定性 | 文案画面对应、区域提示、多源资料编排 | 自动事实核验/自动搜图 |
| 生活/旅行叙事 | 空间→动作→细节→感受 | 多源编排、静音画面停留、原声、选择性音乐点 | 自动理解未拍动作 |
| 游戏/录屏事件回看 | 前因→关键事件→局部回看→解释 | 源区间选择、静态区域引导、独立解说音轨 | 曲线变速、自动跟踪 |
| 第一人称经历解说 | 处境→事件→反应→结果与边界 | 多源画面、独立旁白/原声、明确音画衔接 | 声音克隆或声部分离 |
| 资料局部解释 | 整体定位→区域→关系→整体 | 原图坐标转换、分时静态高亮 | 关键帧形变/移动跟踪 |
| 片头图层组合 | 主信息→层级→协调入场 | 逻辑设计；简单标题有原生时间 | 复杂组运动、动态抠像、透明视频层叠 |
| 按作用安排声音 | 可懂人声→场景原声→有理由的音乐/音效 | 独立轨、增益、淡入淡出、限幅、瞬态候选 | 自动听觉审美判断/音乐生成 |

前五种已加入可发现的预设；完整机制、条件和边界通过 GET `/api/visual/logics` 返回。音画素材未完整观看/听审的部分不升级为已验证的行业效果；课程推广、客户审片方案不进入功能库。

叙事缺关键动作或场景关系时给出补拍清单；图库/示意图不能冒充具体事件。素材、组件和具体方案分开保存，模板不授予素材使用权。当前技术验收与真实内容审美、听审、发布效果分别报告。
