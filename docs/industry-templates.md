# 行业剪辑模板 / Industry editing templates

用户可以直接说：“按餐饮探店模板剪这条视频，继续原项目。”Agent 使用统一入口，读取素材与进度，选择模板、划分段落、检查画面后执行。人不需要记模板 ID、命令或坐标。

| 行业模板 | 段落结构 | 视觉处理与边界 |
|---|---|---|
| 知识教学 / education | 问题 → 演示/解释 → 可复用结论 | 横屏较大资料区、竖屏上部资料区；强调问题和结论；保留步骤及必要等待 |
| 财经商业 / finance | 问题 → 数据/口径 → 限制条件 | 较大图表区、较小字幕；强调问题与边界；数字、单位、基期和时间不可省略 |
| 美业服务 / beauty | 需求/现状 → 部位/服务细节 → 个体边界 | 较小侧边资料区及区域提示；避免遮挡脸部观察目标，不伪造效果对比 |
| 电商产品 / product | 使用场景 → 实物/操作细节 → 适合谁 | 主要资料区展示细节，强调场景和限制；实际性能须有实际材料 |
| 餐饮探店 / food | 环境场景 → 食物/服务细节 → 条件化评价 | 较小配图区保留环境，减少全程强调；不虚构体验或把生成食物当实拍 |
| 家居房产 / property | 居住需求 → 空间/尺寸关系 → 代价与取舍 | 较大户型/空间资料区；强调约束与取舍，不捏造尺寸、预算或实景 |
| 旅行 Vlog（有旁白）/ travel_vlog | 出行目标 → 现场经历 → 感受与条件 | 小资料区、较小字幕；保留场景和体验，不机械剪完停顿，不冒充到访 |

## 根据逻辑生成更多类型

行业、视频形式、观看目的和素材条件分别判断。Agent 可以为旅行日记、探访记录、操作教程、对比评测、访谈或事件回顾生成项目专用逻辑，而不是无限复制固定模板。每个自定义段落都须说明叙事作用、画面安排、节奏理由和声音处理；选择的结构要能被实际素材支持。

通过 `editing-recipe` schema 与 POST `/api/visual/recipes/validate` 检查定义，再作为 editing-template.custom_definition 编译。可执行定义随项目和导出冻结，保留版本与哈希。服务不会自行调用模型；创作与语义判断由调用 Agent 完成。

纯画面旅行 Vlog、审阅后的音乐打点与多源独立声音现使用 native_timeline 定义和[原生时间轴](native-timeline.md)编排；复杂跟踪、组动画、变速或音乐生成等仍标为 planning_only 并列缺项。详细判断见 [Agent 生成方法](../skills/self-media-workflow/references/recipe-generation.md)。

模板包含不同的叙述职责、素材要求、字幕重点和横竖屏布局，不只是颜色预设。时间来自审阅后的 ASR 组和剪切映射，不按固定秒数机械转场。Agent 可针对已检查的画面调整安全槽位、关闭某段强调或使用原画面。模板不会自动重排原片叙事、删除有声内容或引入未知素材。

## Agent 接口

- GET `/api/visual/templates`：实际模板、版本、定义哈希、结构、素材要求、边界与布局。
- `schema editing-template`：严格编译请求；POST `/api/projects/{pid}/media/{mid}/visual-template/compile` 返回 visual_plan 草案。
- 草案经检查后提交现有 visual_plan_save；保存时重编译校验，冻结模板定义与素材。现有导出请求带 visual_plan_id。
- context.visual_plans 包含模板与过期状态；续做使用同一项目，不增设人类启动点。

ASR 样式编译器支持单源视频、完整字幕组强调、本地 PNG/JPEG 与静态区域高亮；原生时间轴另支持无声视频、多源与独立配乐。在线搜图、语义自动选镜、抠像跟踪、复杂动画和音乐生成尚未实现。素材不足会拒绝缺段落/缺图片请求，不补造事实。

protected_regions 由 Agent 看真实画面后标出；服务拒绝图片槽位与其相交。它不自动检测人物，不能独立证明内容属实、画面美观或使用条件已核实。字幕可读性、主体遮挡与声音仍需检查实际输出。

## 验证

当前十二种预设及自定义旅行叙事已经过真实 FFmpeg 合成和完整解码，覆盖横竖屏、安全槽位、缺段落/缺图片、遮挡、乱序或漏词、旧版本、过期审阅、编译结果篡改、规划模式拒绝渲染。原生时间轴另完成独立换素材和实景旅行示例的三端检查，见[本轮验收](../evaluation/native-timeline-20261025.md)。预设技术片不代表各行业真实商业案例，技术通过与内容质量分别判断；历史结果保留在[前轮记录](../evaluation/industry-templates-20261025.md)。

前版遗漏的不露脸资料、科普、生活场景、游戏/录屏事件及第一人称逻辑已补回预设。完整机制和仍缺的组件见[逻辑库](editing-logics.md)。
