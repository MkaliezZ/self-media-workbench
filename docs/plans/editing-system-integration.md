# 剪辑功能整合

版本 v0.3，2026-10-25。本文描述工作台自身的功能、使用条件与验收边界。

## 统一流程

读取任务与项目状态 → 盘点素材 → 确定表达目标 → 选择必要操作 → 保存绑定版本的计划 → 实际合成 → 检查画面与声音 → 保存修订 → 根据发布数据复盘。

行业名称不决定模板。先判断观众需要理解什么、看清什么、现有素材是否足够，再组合编辑组件。只换颜色或行业名称的效果不重复建模块。

## 已接入的首批组件

| 功能 | 输入与执行 | 使用边界 |
|---|---|---|
| 重点字幕 | Agent 选取完整、已审阅的字幕组；整组变色并轻微放大 | 不伪造字符级声学对齐；保留否定、条件、单位和限定语 |
| 文案打点配图 | 实际 ASR 组 ID 锚定本地 PNG/JPEG，指定安全区域，等比容纳 | 图片由 Agent 判断；没有在线自动搜图；不盲目裁图 |
| 图片内区域强调 | 原图归一化矩形经布局变换后高亮 | 静态矩形，不是对象跟踪或智能抠像 |
| 原画面区域提示 | 归一化矩形与明确显示区间 | Agent 检查脸、嘴、动作和 UI 遮挡 |
| 续做与恢复 | 绑定原件哈希、ASR run、审阅版本；成片时间由保留区间推导 | 剪切或恢复使旧计划过期，须重新核对并保存 |

以上复用媒体项目、统一任务入口、项目状态与异步导出。CPU 合成与 ASR GPU 加速分别检查。功能的实际平台验证范围见[视觉编辑](../visual-editing.md)及验收记录。

## 成熟方法的选择条件

| 表达目标 | 组合方式 | 失效条件与退路 |
|---|---|---|
| 人物解释 | 重点字幕突出完整结论或限制；局部配图辅助理解 | 遮挡表情/口型、增加无关信息时移除 |
| 操作教学 | 保留真实步骤、结果与必要等待；区域提示指向实际对象 | 缺关键过程则给出具体补录单，不能靠包装补造 |
| 不露脸解释 | 资料图、简图与字幕分工，主次清楚 | 普通场景图不能冒充具体事件；无适当图片则保留文字或生成明确示意 |
| 数字解释 | 数据、单位、口径、时间一起呈现；标注实际对象 | 没有可靠数据时只画逻辑示意，不生成伪数据 |
| 实物或生活记录 | 保留动作衔接、空间关系和观看时间，克制文字 | 静音不等于无用；不按固定频率加转场或删停顿 |

每个视觉事件必须说明增量作用。素材清单记录文件哈希、性质和使用条件声明；这些是项目执行数据。尚无实测支持的复杂效果不进入可用组件库。

## Agent 执行

1. 根据完整任务决定从哪个阶段开始，读取当前 context，不重做已完成环节。
2. 盘点实际文本、音轨、画面与图片；缺件时推进不依赖缺件的部分。
3. 检查中文字体与 FFmpeg 滤镜，审阅字幕分组，选必要重点和视觉事件。
4. 保存 visual-plan；所有事件绑定实际原句组、原件与审阅版本。
5. 导出并轮询真实终态，检查全片解码与关键帧，涉及声音判断时检查实际音轨。
6. 保留失败、修改理由、旧方案和旧成片；上游改变则重审锚点。
7. 发布后依据同口径数据复盘；没有数据则生成采集计划，不从好看推导增长。

## 后续规划

- 受控素材检索：项目素材 → 本地库 → 已配置供应商。覆盖无配置、零结果、重复、坏文件、无关图片与使用条件不明的退路。
- 条件组合：同一套组件逐类验证录屏、解释与实物形式，不承诺全行业自动生成。
- 动画与声音：先建立独立轨道、时序和可撤回契约，再逐项验收。复杂动画、对象跟踪、抠像、调速、配乐与语音生成目前没有实现。

## 验收与修订

区分契约校验、真实合成、语义与视听判断、真实发布效果。Windows 实测不能写成 macOS 实测，工具执行成功不能写成增长有效。

- v0.1–v0.2：形成视觉操作及项目接点规划，尚无运行实现。
- v0.3：收敛为字幕强调、本地配图与静态区域合成；补入源时间映射、版本过期、失败保留与恢复检查。按功能组织产品说明。
