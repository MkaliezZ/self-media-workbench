# 文案驱动视觉编辑规划

状态：路线图 v0.2，2026-10-25。本地字幕强调、图片布局与静态区域提示已接入；其余仍按下文分期规划，验证范围见视觉编辑文档。

## 目标与使用入口

面向调用工作台的 AI Agent。用户只需描述任务，例如“给这条口播选重点，在有助于理解的地方配图，续做原项目”。Agent 读取项目实际状态、理解文案并提交可追溯的编辑方案，本地服务检查方案与素材并执行渲染；继续使用统一入口，不增加要求人记命令的启动点。

## 已有基础

当前代码已有媒体导入、本地 ASR、字幕校正与分组、明确的停顿及有声片段删除、原片到成片的时间映射、MP4 与独立 SRT 导出、项目版本和失败记录。首批本地视觉合成见 visual-plan schema；自动搜图和配乐仍是规划。

## 拟新增能力

1. 重点选取：支持用户指定和 Agent 建议；每处保存完整上下文、选取理由、原句与实际转写组 ID。否定、条件、程度和数字单位不得因强调被隐去。
2. 重点呈现：关键词变色、加粗、底色、独立文字卡与轻微入场效果；统一主题和字幕安全区，控制同时出现的强调数量。逐字视觉样式可以依照已校正文案分段，但不得据此伪造字符级声学对齐。
3. 语义打点：为解释、证据、步骤、对照和必要的画面变化建立插图事件；记录为什么需要、显示何物、原文锚点、入出点和布局。没有必要则保留原画面。
4. 素材检索：先项目素材，再本地素材库，最后配置的在线供应商；语境生成查询，保留候选、选择及拒绝理由。接口密钥放本机配置，禁止写入项目或仓库。
5. 素材判断：核对主体、构图、清晰度、裁切和文字可读性；区分事实证据、示意图、情绪素材和生成图。普通场景图不能替代具体事件、人物或数据的事实证据。
6. 来源记录：记录原始页、作者、供应商、获取时间、使用条款链接/核查状态、文件哈希和使用位置。在线检索不等于已经获得合适的可用素材。
7. 合成导出：全屏插图、画中画、左右对照、文字卡、样式字幕与可控淡入淡出；增加预览及最终成片，同时保留独立字幕、素材清单和编辑方案。
8. 续做与撤回：原始视频和下载原件不可覆盖；重点、素材与样式分别可修订或撤回。剪切、恢复、换 ASR run、换稿后重新计算依赖与时间，无法自动重绑定的事件标记过期，不猜位置。

## 时间与数据契约（设计方向）

- 源时间为事实锚点；所有视觉事件绑定 source_sha256、asr_run、review revision 和实际转写组，成片时间由统一映射计算。
- 删除范围覆盖的事件不显示；跨越多个保留区间时显式拆分或标记复核，不能粗暴拉长图片。
- 同句重复出现时用组 ID/片段 ID 区分；修改字面文案不等于修改音频。
- 文案尚未录制时只生成镜头/素材需求表，时间为预计；录制后通过实际音轨重新对齐。
- visual_plan 已有独立媒体附属 schema；asset_manifest、style_profile 仍是后续设计。
- 继续复用 context_id、project revision、任务 request_id、依赖与 supersedes/revision_reason；异步渲染须轮询真实终态。

## 分期

| 阶段 | 范围 | 通过条件 |
|---|---|---|
| P0 | 重点与打点方案、已有本地图片、单一模板合成 | 相同项目可续做；否定条件不被误强调；所有事件可回溯原句；切除和恢复后对齐正确 |
| P1 | 在线图库适配、候选审阅、来源清单、缺图退路 | 无密钥/零结果/失效下载可继续；证据图不被示意图冒充；不重复下载同一哈希 |
| P2 | 多内容形式和行业条件配方，视觉与声音规划 | 根据任务和现有素材选择方案，明确缺件，不把行业名称当作固定模板 |
| P3 | 跨系统与独立换素材验收 | Windows 与 macOS 实际渲染、中文字体与路径检查；原件不变；失败、修订和撤回均保留 |

## 验收集

至少覆盖：普通口播、否定/条件句、同句多次出现、删停顿后图片时间变化、恢复片段、横图转竖图、缺图、素材来源缺失、中文路径/字体、旧方案失效、服务重启与续做。语义判断须看实际画面，不能仅用 schema 通过或命令退出码代替。
