# 剪辑与动效参考观察 · 2026-10-31

只观察剪辑手法与视觉动作，不拆解选题、观点、商业逻辑、事实主张或运营表现。功能库采用中性名称与原创示例，来源只在本记录留证。

来源：[用户提供的抖音短链](https://v.douyin.com/K6dBJeYosuM/) → [作品页面](https://www.douyin.com/video/7702665276675902774)，页面署名“大瑞Keaton”，标题《下一门 AI 生意——BOT》。来源记录用于定位作品，不为其内容背书。

本机取得网页实际播放的独立音视频流，封装为一个本地参考文件；视频3840×2160、30fps、122.9秒，音轨约122.922秒。完整解码完成；本地CUDA ASR只辅助核对语音与画面时机，不替代人耳听审。保留原流、哈希、原始识别及取帧；第三方原片、人物、声音、品牌图形、截图和完整转录不进入公库。

观察包含全片每2秒的总览抽样，以及四组每0.5秒的动作序列，共80个带源时间/帧号的细查画面。以下为镜段范围，**不是逐帧测量的全部剪点或精确缓动曲线**；没有连续逐帧观看，也没有听审，不推断软件、制作工程或动效实现代码。

| 约略范围（源秒） | 只描述画面手法 | 可复用的剪辑决定 |
|---|---|---|
| 0–3.8 | 真人居中；左右卡片先后出现；非重点卡片降明度，另一张用亮色收尾 | 一次只建立一个新的注意点；两项对照避免同时抢主信息 |
| 3.8–9.3 | 大面积页面资料；侧边标题；角落圆形真人窗；局部浮卡覆盖页面 | 资料接管主画面时，保留人物连续性；标注与主体分层 |
| 9.3–15.1 | 中心图标→周边节点→弧线→沿线小图标移动；随后换一侧竖窗 | 对象先于关系；复杂路径粒子与简单关系连线分开记录 |
| 15.1–23 | 文档卡逐行写入、叠放、数字放大、图标从少到多 | 用写入/复制/数量变化承载动作，不靠整屏花哨转场 |
| 23–33.7 | 回真人干净讲述，几段保持同一机位和低画面负担 | 动效段之后给视觉呼吸；不用固定切频压满整片 |
| 33.7–38.9 / 44.1–48.9 | 插入角色化类比视频后回到图解或真人 | 已有/另行授权生成的类比素材是B-roll；剪辑库不据此声称三维生成 |
| 38.9–44.1 | 双卡对照；一侧展示内部，另一侧隐藏并加标记 | 对照靠信息可见性差异完成；不能把隐藏层伪造为事实 |
| 48.9–55.4 | 一侧真人竖窗；文字划线降权；清单逐项勾选；下排小卡递增 | 大标题、列表、底部附属行分层，字幕单独保留 |
| 55.4–58.5 | 回真人，随后缩小移到角落并切入图解 | 版式变化有明确进入时机；不把角落窗当另一机位 |
| 58.5–66.3 | 单个图标→周边多个→规整矩阵；中心结论出现，背景图标逐步变暗 | 先展开集合，再降低背景权重；图标不是实际统计值 |
| 66.3–70.5 | 真人画面配角落短标题、下划线，再转图解 | 章节提示只承担导航，不重复整段字幕 |
| 70.5–83.1 | 中心图形持续保留；椭圆圈层描画、标签增加、周边细节进入 | 每次只增一层，旧层不消失；层级不代表可量化强度 |
| 83.1–95.5 | 真人过渡；单卡→多节点串联；下方滑条和指示点移动 | 从局部到完整流程；滑条属说明性动作，不自动具有量纲 |
| 95.5–103.5 | 流程节点依次点亮、数值逐步变化；局部节点变色、分支偏离；再回真人 | 用递进、颜色和路径偏离区分状态；示意数值与实测数据分开 |
| 103.5–119.2 | 真人与图解交替；多卡统一排布；连线汇聚；单图标、环线和柱形收束 | 同一视觉系统收尾；保留中心对象，避免连续新建无关版式 |
| 119.2–122.9 | 回真人完成结尾 | 结束前给稳定人像与完整语音，不强加片尾动画 |

可观察的统一视觉语法：暗背景、浅文字、局部暖色强调、细线、轻纹理、圆窗与竖卡；颜色与形状只是参考。本库仍使用工作台自己的蓝/粉强调色和简洁图形。观察到的连续圆角缩窗、曲线小图标路径、三维角色动作，不能从截图推断其原始工程实现。

入库结果是[口播与图解交替规则](../docs/explanatory-diagrams.md)、四个原创参数化组件，以及原有组件的组合映射。并未复刻参考原片，也未导入其内容结论。
