# 新轮独立轨道遮罩验收准备包

主题为原创“深海观测窗口”。全部插画、运动视频、遮罩、PNG观察框和音轨都是自制合成素材，不是真实拍摄或观测数据；不复用主片及此前文章/纸船/FX测试素材。

`SEALED_TRACK_MATTE_TASK.md` 固定20秒/600帧的完整任务、alpha/luma正反向探针、24像素羽化移动圆窗、透明PNG孔和前后遮挡对照/恢复，以及旧溢出计划的保存/导出预检复验。`materials/matte_calibration.json` 固定具体像素、源裁剪、时钟与图层几何。`generate_matte_materials.py` 可重复生成所有新素材。

alpha PNG故意把黑白RGB与0/64/128/255的Alpha分离；luma PNG全Alpha255但灰度不同。另一PNG有透明圆洞及真正不透明十字梁，透明洞下保留洋红RGB。实际视频通过遮罩显示才算通过，不能把黑白/洋红遮罩图本身显示出来代替。

本包在收到新组件SHA前封存，尚未阅读未来主展示片、主测试或track_matte实现/schema。当前只准备材料与标准，不宣称新组件已通过。原3109报告PARTIAL及旧素材/失败保持不变，新轮只追加。

Windows收到SHA后执行；Mac须以原生CI独立证据为准。没有任意曲线、自动抠像或真实运营效果的预设通过要求。
