# 独立新增轨道遮罩验收：深海观测窗口

本任务在收到新组件SHA之前封存；不读取未来主展示片、主测试或其预期答案。全部为新制深海插画/运动视频、遮罩和声音，不复用主片、此前文章/纸船/FX素材。明确不是实拍、真实深海观测或真实账户。

## 固定输出：1280×720，30fps，20秒/600帧

deep_background.png作为完整底图；deep_rover_960x600_25fps.mp4是唯一实际前景视频。取源像素(180,0,600,600)的中心正方形，保持源时间连续0–20秒。原音频为无声，新原创时钟音轨从0秒连续铺到20秒，低音量，无ASR。

0–16秒将前景窗口放在成片(384,104,512,512)，四段各4秒：

1. 0–4秒：matte=independent_alpha_bands.png，mode=alpha，invert=false，源视频0–4秒。
2. 4–8秒：同一alpha遮罩，invert=true，源视频4–8秒。
3. 8–12秒：matte=independent_luma_bands.png，mode=luma，invert=false，源视频8–12秒。
4. 12–16秒：同一luma遮罩，invert=true，源视频12–16秒。

每段from_rect=to_rect相同；使用公开组件可表达的短入场/合法hold，不要求任意曲线。各段中点2/6/10/14秒是稳定透明度探针。mode=alpha必须只用实际Alpha，不得把遮罩RGB当画面贴上；mode=luma按灰度0/64/128/255产生0/0.251/0.502/1遮罩，不能因为该PNG的alpha全255而整窗不透明。invert为1−遮罩，不翻转源画面或时间。

16–20秒：使用independent_feather_circle.png作为alpha遮罩，前景视频源16–20秒；窗口320×320，由(100,280)移到(800,120)，使用smoothstep端点运动，enter=3.5秒，合法hold=0.5秒，无退出淡出。圆形蒙版向内羽化在320窗口下为24成片像素。实际视频必须随窗口运动且源动画继续，不能仅移动边框或贴静帧。

17–19秒把independent_foreground_hole.png按(460,160,360,360)放在移动视频上方。PNG透明洞里应见后方视频或底图，透明像素下隐藏的洋红RGB不能泄漏；不透明十字梁/外框真实遮住视频。首片后另保存/导出一版仅改变前后顺序，把这个PNG放在移动视频下方：有交叠处视频应盖过梁，而洞仍透明。再按当前head恢复首片顺序并实际导出，不覆盖首片/对照/旧计划。

## 预先固定的验收判据

- 实际解码600帧、20秒视频、1280×720/30fps，无解码错误。容器/AAC差异不超过一输出帧并报告，不允许少视频帧。所有原始素材、首计划和首片哈希记录且保持不变。
- 以真实解码源视频和底图做逆向合成测alpha，不以plan字段或API成功代替。四段中点的稳定探针预期：[0,0.251,0.502,1]或对应反向[1,0.749,0.498,0]，容许编码/重采样绝对误差0.04。每档取避开图形边界的小ROI中位数；原始RGB黑白与alpha正交的探针必须证明alpha模式忽略RGB。透明孔探针应正向0、反向1。luma使用完全不透明PNG，必须证明读取灰度而非误用alpha。
- 四段必须显示同一原视频对应的源时刻，不得重启每段素材或把黑白遮罩本身当画面输出。对源帧量化容许一源帧，视频动作/可见源时间标记/对应像素分别取证。独立音乐在跨段窗口与原PCM相关，偏移不超过一输出帧，相关至少0.96。
- 移动圆窗在19.5–19.9秒稳定hold时测其内区alpha至少0.95、圆外角点alpha至多0.03，羽化带有至少8个连续成片像素落在alpha0.15–0.85，至少5个中间级；不能以硬边圆或全矩形淡入冒充。入场期间若组件带整体fade须明确记录，并与空间蒙版分开测量。以实际声明的smoothstep端点为依据，采样位置误差不超过8像素；不声称任意曲线/跟踪或自动抠像。
- 18秒附近的PNG洞/梁/前后交叠做像素取证：洞内非梁区能看到真实后方，梁区首片由PNG遮住、改顺序后由视频按实际入场透明度叠到梁上，透明洋红不能出现。只改变顺序不能改变视频源时间、其余效果和总帧数。
- 恢复版在同一主机参数下解码视频和PCM哈希与首片一致；容器差异另报，不得用元数据解释内容变化。
- 非法matte_id、非图片matte、未知mode、无法解释为布尔的invert（如not-a-boolean）、零/负crop或slot、越界、源/效果超时，均须在有效计划/导出前清晰拒绝，不移动有效head、不覆盖已完成文件。若存在0/1或true字符串的类型兼容转换则单独报告，不预猜严格类型策略。没有字段的任意曲线/自动抠像只列NOT_SUPPORTED，不以虚构字段验既有功能。
