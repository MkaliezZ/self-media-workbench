# 独立 FX 盲测任务：夜航观测站

本任务在收到待验 FX commit 之前写定，与旧版旅行时间轴封存任务独立。素材为自制动态观测站插画及原创合成音乐/环境音，不是真实拍摄，不含第三方媒体、付费资源或主仓库 fixture。以“捕获信号—对准目标—传回数据”为统一主题，输出一条完整、有意义的样片，而非互不相关的小测试拼盘。

## 首次完整样片

- 输出 1280×720、30 fps。三个底层片段按 R→S→U 排列，均 contain 不裁切：R 源 1–5 秒（4 秒），S 源 1–6 秒（5 秒），U 源 0.5–6.5 秒（6 秒）。不改变源播放速度。
- R→S 使用 0.5 秒 fade 转场；S→U 使用 1 秒 wipeleft 转场。转场消耗片段重叠，不凭空延长停留：R 在成片 0–4 秒，S 在 3.5–8.5 秒，U 在 7.5–13.5 秒。成片严格为 13.5 秒、405 个视频帧；两段转场分别在成片 3.5–4、7.5–8.5 秒。若产品无法表达，记录真实缺项，不改变标准。
- 原创 120 BPM 音乐从源 0 秒、成片 0 秒连续播放至 13.5 秒，增益 0.6，结尾 0.25 秒淡出；R/U 原声增益 0.2，S 无音轨仍保留“TARGET CONFIRMED”画面。交叠时原声可交叉衰减或明确混合，不能把音乐按镜头重启。
- 使用同一个 F 诊断画面作两次局部合成，图层本身先等比缩至 320×320：矩形图层在成片 1–3 秒、左上角 (800,160)，对应 F 源 2–4 秒；圆形图层在成片 9–11 秒、左上角 (180,220)，对应 F 源 7–9 秒。两个图层都要真 alpha 遮罩和 24 个成片像素的羽化，不能用画一个框或实色覆盖伪装。
- 矩形遮罩形状覆盖该 320×320 图层边界，羽化向内形成平滑边缘；圆形遮罩为该图层正中、半径 160 像素的圆，圆外透明，羽化向内。若 schema 使用归一化数值，按同一物理几何换算；不预先猜 schema 字段。
- 加三条完整的主题标题，使用成片时间：`SIGNAL LOCK` 3.7–4.3 秒，`CAPTURE WINDOW` 7.8–8.8 秒，`UPLOAD COMPLETE` 11.5–13.2 秒。标题居中靠下、白色，字号约 36 像素，底边距约 58 像素；具体字体采用产品可用系统字体，不带字体二进制。前两条跨转场，不能因镜头边界被截断、重复或挪动。

## 对照、修订与续做

1. 首次先保存并实际导出上面的完整样片，保留首次请求、响应、导出和失败。不得先用外部工具拼出“期望成片”交给产品照抄。
2. 新建一个仅移除 F 图层的对照版本，保留底层、转场、标题及音乐。实际导出，供 alpha 检查时估计背景。不能覆盖首次成片。
3. 按最新 head/项目版本将最初完整决定恢复为新版本，再实际导出。恢复版在同一主机、同一参数下，应与最初完整成片拥有相同解码画面/PCM 内容；容器元数据差异单列，不能掩盖内容差异。
4. 重启属于该隔离工作台且已空闲的服务，通过统一入口续做同一项目。旧的纯时间轴计划（如原独立任务的计划，或在本项目先保存的无 FX 方案）应能按兼容语义读取、继续及导出，不能被新字段默认值损坏。不能更改旧封存任务/原文件来达到兼容。
5. 使用新请求 ID 和当前项目版本测试错误参数：负/零转场时长、转场长于任一相邻片段、未知转场种类、羽化负值、遮罩几何越界或空尺寸、图层超出成片时长、错误 source ID。应在导出前返回清楚的错误；非法尝试不移动有效 head。旧项目版本仍需拒绝。

## 预先固定的验收判据

- 实际解码 405 帧、1280×720/30 fps，视频时钟严格 13.5 秒；容器/AAC尾部差异允许不超过一帧但必须报告，不能少视频帧。完整解码无错误、无意外黑帧。源与首轮成片哈希记录并复核未变。
- 检查每一转场前后相邻帧，以及 fade 中部与 wipe 的 25%/50%/75% 位置。转场前后应只见正确的源和正确源秒数；重叠区源时钟都持续推进，不能冻结、重复多消耗/少消耗源时间。fade 中部多个稳定像素应显示两源混合；wipe 应存在两源空间分区并沿同方向逐帧移动，不能用硬切或全帧 alpha fade 代替。
- 与无图层对照版及真实 F 解码像素比较估算 alpha。两种形状中心 alpha 至少 0.95；形状外/圆外角点 alpha 至多 0.03（编码误差已包括）。远离遮罩及标题区的背景应保持不变。羽化边缘必须有至少 8 个连续成片像素的过渡带，且沿法线至少观察到 5 个不同的中间 alpha 值，覆盖 0.15–0.85 范围；边缘不能只有硬二值跳变。容许羽化函数不同，不能因此把“24像素羽化”降成近似硬边。
- 标题按全局成片帧检查：分别在第111帧出现/129帧消失，第234帧出现/264帧消失，第345帧出现/396帧消失；允许字体栅格化与编码误差，不能有整帧时钟漂移。音乐在无原声的独立窗口与源 PCM 做相关，对齐偏移/漂移不超过一输出帧，相关系数至少0.96；在跨转场后再次测量，不能只验证开头。
- 所有结果依据真实视频帧、PCM、版本与失败记录；schema通过、计划已保存、API done不算独立通过。图像/波形技术通过不代表人工审美、真实旅游或发布效果。
- Windows、Apple Silicon、Intel macOS 分别保留原生主机、commit、调用、原始请求、真实输出、独立检查报告与全部失败。不能用平台模拟或某一主机通过代替其他主机。

本文件、素材与生成脚本会在开始产品盲测前封存 SHA-256。收到 commit 后才读对应 README/AGENTS/skill/schema；主实现和测试预期不作为本任务答案。
