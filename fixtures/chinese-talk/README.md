# Synthetic Chinese speech fixture

Repository-authored test text, native Windows synthetic speech (Microsoft Huihui Desktop) and a generated blue background. No person/customer footage or voice model is distributed. The common MKV contains 16 kHz mono PCM, so all platforms receive identical audio/video bytes rather than different native voices or AAC encoders. `fixture.json` records the source/PCM hashes, exact TTS text and generated segment/gap bounds.

Pause A is deliberately inserted and may be removed then restored. Pause B is a demonstration hold and must remain. Numbers are test readings, not recommended production settings. The known TTS script supports reference-assisted local substitutions; it must not be used to fill missing ASR groups, fabricate alignment or report corrected text as original model accuracy. Normalized error measurements distinguish Chinese orthography/numeric formatting from actual recognition errors. This single synthetic short fixture is not a human/noisy/long-form speech benchmark.

The immutable first fixture has 48.5063125 seconds of PCM and 50.2 seconds of video/container duration (the generated video tail is longer). Restore coverage is measured against the probed 50.2-second source, rather than silently truncating it to the audio length. Native TTS padding precedes the inserted A gap: the VAD candidate may start earlier, and may only be removed after verifying that its entire union with A is silent in decoded source PCM. Keep this original fixture/hash across failed and repaired runs.
