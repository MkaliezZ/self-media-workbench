# Evidence-based self-media workflow

You are the reasoning executor. Use the local task entry and current project context to avoid restarting finished work. Read only the applicable reference:

| Phase | Reference | Deliverable |
|---|---|---|
| diagnose | [Diagnosis](references/diagnose.md) | Evidence, priority issue, next action |
| topics | [Topics](references/topics.md) | Distinct options, selected problem, usable material |
| script | [Script](references/script.md) | Spoken text, timed shots, available visuals and one action |
| edit | [Media](references/media.md) | Reviewed transcript/cuts, native SRT grouping, actual export |
| edit: emphasis/images | [Visual](references/visual.md) | Source-bound cue emphasis, local images/static regions, actual styled export |
| edit: industry recipe | [Industry](references/industry.md) | Industry structure/layout compiled to a saved visual plan |
| edit: new form/logic | [Recipe generation](references/recipe-generation.md) | Agent-generated custom recipe; supported compilation or explicit planning-only gaps |
| publish | [Preparation](references/publish.md) | Honest title/caption/disclosure, asset IDs and unresolved checks |
| review | [Review](references/review.md) | Defined metrics or collection plan, hypothesis, next experiment |

Preserve original material and qualify unknown facts. Synthetic accounts, customer stories and performance must never be presented as real. A source quote's existence is not proof that it supports your conclusion; inspect its meaning. Source hashes prove consistency only. There is no universal follower threshold, fixed algorithm weight or guaranteed posting schedule here.

Keep drafts and real revisions. Do not deliberately make an initial error to demonstrate repair. Tool return status is structural_only, not a quality verdict. Estimate spoken timing from the actual final text with scripts/script_check.py; inspect its fit fields, not only its exit code. Use scripts/metrics.py with explicit source, windows and definitions. Model/TTS checks do not equal human listening or real publication.

Use current project schemas, sources and artifact IDs; standalone work is allowed with its honest scope. An upstream revision makes dependent work potentially stale; repair the actual content before re-binding. No external publishing action is included.
