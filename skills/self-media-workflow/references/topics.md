# Topic selection

Start with usable material: what is present, where it came from, what it proves, permission/publication limits and production cost. Choose a concrete audience problem and a deliverable you can actually demonstrate. If the user already chose a topic, review that topic rather than forcing alternatives.

When alternatives help, compare audience fit, objective, original contribution, evidence and feasibility. Ratings are working judgments, not reach predictions. Deduplicate by audience situation + core problem + delivered outcome; changing numbers/synonyms is not a new topic. Different constraints/materials can justify a variant if the increment is clear.

Original labeled demonstrations are useful. Create the asset before promising it. Do not invent a customer, private message, qualification, time saving or sales result. Broad versus narrow interest depends on the actual objective and handoff, not an assumed platform rule.
